# certifly brand

Source files for the certifly mark. The web app serves copies from `public/`.

| File | Use |
|---|---|
| `certifly-icon-dark.svg` | Mark with dark ink (`#0b1220`) for light backgrounds |
| `certifly-icon-light.svg` | Mark with white ink for dark backgrounds |
| `favicon.svg` | Favicon; switches ink via `prefers-color-scheme` |
| `icon-192.png`, `icon-512.png` | Web app manifest icons |
| `icon-maskable-512.png` | Maskable manifest icon (purple background, 80% safe zone) |
| `apple-touch-icon.png` | iOS home screen, 180×180 |
| `tokens.css` | Brand and certificate-state colours |

The name is always written in lowercase: **certifly**. There is no wordmark file yet; the app
sets the name in text next to the mark.

Mark colours: ring `#0b1220` / `#ffffff`, plane `#5b47c9` + `#3f2fa0` (light backgrounds) or
`#9d8ff0` + `#7a69e6` (dark backgrounds).
